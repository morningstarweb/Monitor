# Monitor support

For product usage and connection issues, start with:

- [README](README.md) for features and setup;
- [Networking guide](docs/networking.md) for LAN, WebRTC, TURN, and relay diagnostics;
- [Architecture map](docs/architecture.md) for component ownership;
- [Development guide](docs/development.md) for builds and checks.

For a reproducible bug report, include the Monitor version, Windows/Android versions, selected connection route, and steps to reproduce. Remove access tokens, account identifiers, and private repository data from logs and screenshots.

Use the GitHub issue tracker for non-security defects and feature requests. Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
